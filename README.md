# Bright Future Library

Standalone React and Vite frontend for the Bright Future Library sample site.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

All application source and book-cover illustrations are contained in this folder. The contact form is a frontend demo and does not send or store messages. Update the sample library contact details, events, and team in `src/App.jsx`.
